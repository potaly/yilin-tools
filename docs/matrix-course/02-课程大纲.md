# 《全平台自媒体矩阵实操》培训课程大纲

- 版本：v1.0（2026-10-22）
- 方案依据：[01-实现方案.md](01-实现方案.md)
- 配套资产：[03-提示词与模板.md](03-提示词与模板.md)

---

## 1. 课程定位

**不教「怎么做自媒体」，教「怎么把自媒体做成一条能稳定运转的流水线」。**

和市面上课程的差别要在第一节课讲明白：

| 常见课程 | 本课程 |
|---|---|
| 教提示词合集 | 教工序、交付标准和目录纪律（提示词只是其中一环） |
| 承诺「一键全平台自动发布」 | 直接告破：哪些平台有接口、哪些永远要人工，把力气花在收益最大的「适配」上 |
| 讲案例、讲心法 | 每节课有交付物，结课要交一周真实发布记录 |

### 1.1 三类学员，三个版本

| 版本 | 对象 | 目标 | 时长 |
|---|---|---|---|
| **基础班** | 不写代码的运营、老板、个人创作者 | 用 WorkBuddy + 文件夹规范把流水线跑起来，不写一行代码 | 6 节 × 90 分钟 |
| **进阶班** | 有一点技术基础、愿意装命令行工具 | 加上 Codex 写 3–5 个脚本，把重复动作自动化 | 基础班 + 3 节 |
| **陪跑班** | 已有账号、要出结果的团队 | 四周陪跑，带着真实账号跑完两轮复盘 | 4 周，每周 1 次直播 + 1 次答疑 |

基础班必须**独立成立**——不依赖任何代码能力。进阶班是可选加购，否则 80% 的学员会在第一节课掉队。

## 2. 基础班大纲（6 节）

每节固定结构：**讲（25 分钟）→ 现场演示（25 分钟）→ 学员动手（30 分钟）→ 交作业点评（10 分钟）**。
没有「动手」那 30 分钟的课，第二节课出席率就会掉一半。

### M1 认知与边界：矩阵到底是什么（90 分钟）

- 工作量的真实分布：为什么「写得快」不是瓶颈，「适配 + 纪律」才是
- **平台能力矩阵**：五个平台分别能自动到哪一步（直接用方案里的那张表讲）
- 当场破除三个幻觉：全自动发布、一稿多投、买个工具就能起号
- 定位作业：一句话说清「我给谁、解决什么、用什么形态」
- **交付物**：个人定位卡 + 选定 3 个主力平台
- **验收**：定位卡里不能出现「分享干货」「记录生活」这类无指向词

### M2 环境与纪律：把流水线搭出来（90 分钟）

- 安装 WorkBuddy，接上模型（自备 Key 或内置模型），跑通第一个任务
- **建 `~/matrix/` 目录结构 + 命名规范 + frontmatter 状态字段**（本课重点，不是装软件）
- 写三份规范文件：`选题标准.md`、`语气词典.md`、`禁用词.md`
- 「任务卡」写法：一张卡 = 角色 + 输入路径 + 输出路径 + 完成定义 + 禁止事项
- **交付物**：能跑的目录 + 三份规范 + 第一张任务卡
- **验收**：让 Agent 按卡产出一次，输出文件名和位置完全符合规范

> 教学提示：这节课最容易被学员当成「浪费时间的准备工作」。必须现场演示「规范缺失时 Agent 产出一团乱麻」对比「规范齐全时一次就对」，让他们亲眼看到差别。

### M3 选题引擎：从「没灵感」到「选题池永远有 20 条」（90 分钟）

- 选题的四个来源：评论区与私信、同行近 30 天高赞、搜索下拉词与后台搜索词、自己的真实经历
- 选题卡五要素：人群 / 场景 / 痛点一句话 / 预期形态 / 证据链接
- 选题打分表（可发性 × 我能讲 × 搜索量 × 竞争度）
- WorkBuddy 定时任务：每天早上 8 点产出「今日 5 个候选选题 + 理由 + 证据」
- **交付物**：填满 20 条的选题池，其中 5 条打过分
- **验收**：每条选题能当场说出「谁会点开、为什么」

### M4 一稿多形：母稿与平台适配（90 分钟）—— 全课最核心

- 为什么要有「母稿」：唯一真相，避免四个平台各写一遍、互相矛盾
- 母稿标准：1500–2500 字、每个论点配具体案例或数据、零废话开头
- **四份适配稿的差异点**（现场对照演示同一母稿的四种开头）：
  - 公众号：标题党有限度、小标题分段、结尾引导在看/转发
  - 小红书：标题 20 字内带情绪钩子、正文口语化短句、话题 5–8 个、图卡拆页
  - 口播脚本：前 3 秒钩子、每句不超过 15 字、分镜表
  - 朋友圈：一句话 + 一张图，不发链接发「图 + 一句」
- 用本站「长文图卡」把母稿转成小红书图卡（实操）
- **交付物**：1 条母稿 + 4 份平台稿 + 一组图卡
- **验收**：四份稿开头互不相同；把四份稿打乱给同学看，能认出各属哪个平台

### M5 短视频：爆款复刻的正确做法（90 分钟）

- 先讲边界：学结构不搬素材；AI 生成内容必须标识（2025-09-01 起施行的标识办法）
- 20 条拆解表现场填 3 条（钩子句、0–3 秒画面、结构类型、信息点时长、结尾 CTA、首评）
- 换壳：同一结构换成自己的案例，产出 10 个候选
- 成片流水线：口播稿 → 分镜 → 素材 → 剪映模板（固定字幕样式 / 片头 / 封面版式）
- **交付物**：10 条拆解表 + 1 条成片
- **验收**：成片前 3 秒能让人不划走（现场投屏，同学举手表决）

### M6 发布、质检与复盘：让它跑过第三个月（90 分钟）

- 发布节奏表：哪个平台几点发、每周几条（按平台特性，不是越多越好）
- **发文前质检清单**（禁用词、错别字、AI 标识、字数、话题数、首评、封面手机预览）
- 数据回流表：填哪 5 个字段、每周什么时候填
- 周报：找出超均值 2 倍的那条，把结论**写回 `选题标准.md`**——这是整条流水线唯一的学习机制
- 结课作品说明
- **交付物**：发布记录表 + 第一份周报
- **验收**：周报里有一条「下周选题标准改成什么」的具体修改

## 3. 进阶班（+3 节，面向愿意用命令行的学员）

### A1 用 Codex 把重复动作变脚本（120 分钟）

- Codex 是什么、怎么装、怎么给它说清需求（需求 → 验收标准 → 让它写测试）
- 现场写第一个脚本：`lint` 发文前质检（扫禁用词、字数、话题数、AI 标识）
- **交付物**：能在自己机器上跑的 `lint`

### A2 公众号草稿自动推送（120 分钟）

- 公众号接口的真实门槛：服务器端调用、`access_token` 缓存、**IP 白名单**、封面要永久素材 `media_id`、正文图片要换成微信域名 URL、标题 32 字
- 现场跑通：Markdown → HTML → 上传封面 → 推进草稿箱 → 手机上看草稿
- 为什么**停在草稿**不直接发布
- **交付物**：一条从本地 Markdown 推到自己公众号草稿箱的真实记录

### A3 批量图卡与数据回流（120 分钟）

- 调用图卡引擎批量出图（一条命令出一整组）
- 数据回流表 → 周报自动生成
- 把脚本挂给 WorkBuddy 定时调用：每天早上选题、每晚待发清单、每周一周报
- **交付物**：三个定时任务都能自己跑起来

## 4. 考核与结课作品

**结课作品 = 一周真实运转记录**，不是交一篇稿子：

| 项 | 要求 |
|---|---|
| 内容量 | 3 个平台 × 1 周 ≥ 9 条（可同源适配，但适配稿必须各自不同） |
| 流水线证据 | `~/matrix/` 目录截图，六道工序的文件都在正确位置 |
| 质检 | 每条都附质检清单勾选记录 |
| 复盘 | 1 份周报，含「最好的一条 + 原因假设 + 选题标准的修改」 |
| 口头答辩 | 3 分钟讲清「这一周我的选题标准改了什么」 |

**不通过的典型**：内容都在、但选题标准一个字没改——说明没形成学习闭环，只是手动劳动。

| 物料 | 说明 | 状态 |

| 讲师逐字稿 | 每节 90 分钟的时间切分与演示脚本 | 待写 |

| 演示素材 | 一条真实母稿 + 四份适配稿的对照样例（学员最认这个） | 待准备 |
| 演示账号 | 一个真实在跑的小号，能展示后台数据 | 必备 |
| 失败案例集 | 判重限流、AI 未标识被处理、Agent 产出跑偏的真实截图 | 必备，杀伤力最大 |
| 配套工具 | 本站「矩阵内容工作台」（可选，见方案路线 C 第一步） | 待评估 |

> 演示素材和失败案例集是课程口碑的分水岭。纯讲方法论的课，学员回去就忘；有对照样例和失败截图的课，学员会截图转发。

## 6. 排课与商业化建议

| 形态 | 内容 | 适合 |
|---|---|---|
| 公开课（免费，60 分钟） | M1 的平台能力矩阵 + 现场演示一稿四投 | 引流，转化靠「原来自动发布是伪需求」这个反差 |
| 基础班 | 6 节 + 模板包 + 一次作业点评 | 主力产品 |
| 进阶班 | +3 节脚本课 | 加购，筛出愿意动手的人 |
| 陪跑班 | 4 周，带真实账号 | 高价，但要控制人数（≤10 人），否则点评质量崩 |
| 工具包单卖 | 模板包 + 提示词资产 + 清单 | 低价引流品 |

定价不在本文档范围，但有一条原则：**基础班卖「能跑起来的流水线」，陪跑班卖「真实数据」。** 不要在基础班里承诺涨粉。

## 7. 第一期落地顺序

1. **自己先跑两周**（纯路线 A，不写任何脚本），把每一步的真实耗时记下来——这些数字就是课程里最有说服力的内容
2. 从这两周的产出里挑出演示素材和失败案例
3. 先录/讲 M1 当公开课，看反馈再定基础班排期
4. 基础班跑完一期，再决定要不要做进阶班和站内配套工具
