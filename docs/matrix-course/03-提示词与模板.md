## 0. 任务卡的通用格式（最重要的一张模板）

给 Agent 的指令不要写成聊天，写成卡。每张卡五段，缺一段就会跑偏：

```markdown
# 任务卡：<工序名>

## 角色
你是 <什么赛道> 的内容编辑，读者是 <具体人群>。

## 输入
- 读取：~/matrix/02-母稿/master-<topic>.md
- 参考规范：~/matrix/_规范/语气词典.md、~/matrix/_规范/禁用词.md

## 输出
- 写入：~/matrix/03-平台稿/小红书/xhs-<topic>.md
- 格式：第一行标题，空行，正文，空行，话题行（# 开头，5–8 个）

## 完成定义
1. 正文 ≤ 1000 字，每段 ≤ 3 行
2. 标题 ≤ 20 字且带情绪钩子
3. 不出现禁用词.md 里的任何词
4. 所有事实、数字只能来自母稿，不得新增

## 禁止
- 不要编造数据、案例、人名
- 不要改写母稿里的结论
- 拿不准的地方留 `TODO:` 标记，不要自己猜
```

> **「拿不准就留 TODO」这一条是全套资产里性价比最高的一行。** 它把 AI 最大的毛病（编造）变成了一个你可以搜索的标记。

## 1. 选题雷达（每日定时任务）

```markdown
# 任务卡：每日选题雷达

## 角色
你是 <赛道> 的选题编辑。

## 输入
- 读取 ~/matrix/_规范/选题标准.md（上周复盘刚更新过，以它为准）
- 读取 ~/matrix/05-已发布/publish-log.csv 近 14 天记录，避免重复选题
- 素材来源：<粘贴你固定看的 3–5 个来源：榜单页/同行账号/评论区导出/搜索下拉词>

## 输出
写入 ~/matrix/00-选题池/topic-<YYYYMMDD>-<关键词>.md，每个选题一个文件：

---
status: 候选          # 候选 | 已选 | 已发 | 废弃
人群:
场景:
痛点:                 # 一句话，必须能说出「谁在什么时候会难受」
预期形态: 图文 | 短视频 | 都行
证据: <链接或数据>
打分: 可发性_/5 我能讲_/5 搜索量_/5 竞争度_/5
---

## 完成定义
1. 产出 5 条，每条都有证据链接，没有证据的不要写
2. 每条用一句话说明「为什么现在发」
3. 与近 14 天已发选题重复的直接丢掉，不要凑数

## 禁止
- 不要给「XX 的 10 个技巧」这类无人群指向的泛选题
- 不要编造数据来源
```

## 2. 爆款拆解表（短视频）

一条视频一行，填满 20 行再找共性。AI 可以帮你填，但链接和样本必须你自己选。

| 字段 | 填什么 |
|---|---|
| 链接 / 账号 | |
| 数据 | 播放 / 点赞 / 评论 / 收藏（记录日期） |
| 标题 | 原文照抄 |
| 钩子句（0–3 秒说的第一句） | 原文照抄 |
| 0–3 秒画面 | 一句话描述 |
| 结构类型 | 痛点→反转→方法 / 清单 / 故事 / 对比 / 拆解教学 / 情绪宣泄 |
| 信息点与时长 | 第 1 点 0:03–0:12、第 2 点 … |
| 情绪曲线 | 平 / 先低后高 / 持续递进 / 反转 |
| 结尾 CTA | 原文照抄 |
| 被顶起的首评 | 原文照抄（这条最能看出真实爆点） |
| 可借用的是什么 | 只填「结构 / 钩子句式 / 选题角度」，不填素材 |

拆解提示词：

```
下面是 20 条同赛道高播放视频的链接与我整理的文字记录。
请逐条填写拆解表的字段，不要评价好坏，只做客观记录。
全部填完后，输出三段分析：
1. 这 20 条里重复出现 3 次以上的结构类型，各举例
2. 钩子句的句式归纳（给出可套用的句式模板，不少于 5 个）
3. 哪些是赛道通用、哪些是某个账号的个人风格（我不该照搬的）
素材不足的字段写「无法从记录判断」，不要推测。
```

## 3. 母稿

```
我要写一篇关于 <选题> 的文章，读者是 <人群>，他们的痛点是 <一句话>。

我的素材（只能用这些，不得新增事实）：
<粘贴：你的真实经历、数据、截图文字、访谈记录>

要求：
- 1500–2500 字
- 开头 3 句之内进入具体场景，禁止「随着…的发展」「在当今社会」这类开头
- 至少 3 个具体案例或数据，每个论点后面必须跟一个例子
- 结论要能落到「读者今晚就能做的一件事」
- 不确定的地方写 TODO: 并说明缺什么素材

先给我文章骨架（标题 + 小标题 + 每节一句话要点），我确认后再写全文。
```

> **「先给骨架，确认后再写全文」要写进课程**。直接出全文的，改一次等于重写。

## 4. 四个平台的适配提示词

### 4.1 公众号

```
把下面的母稿改写成公众号文章。
- 标题给 5 个候选：2 个直给价值、2 个带悬念、1 个数字型，都 ≤ 20 字
- 正文保留母稿全部论点，加小标题分节，每节 ≤ 400 字
- 段落之间口语化过渡，不要「首先其次最后」
- 开头第一段必须和小红书版完全不同
- 结尾一句话引导转发，不要「点赞关注不迷路」
- 正文里需要配图的位置写 [配图：说明]
母稿：<粘贴>
```

### 4.2 小红书

```
把下面的母稿改写成小红书图文笔记。
- 标题 ≤ 20 字，带情绪或身份钩子，给 10 个候选
- 正文 ≤ 1000 字，每段 ≤ 3 行，多用换行和 emoji（每段最多 1 个）
- 第一句话就要让人觉得「这说的是我」
- 结尾一个具体提问，引导评论
- 话题 5–8 个，按「大词 2 个 + 中词 3 个 + 精准长尾 2 个」配
- 另外输出「图卡版」：拆成 6–8 页，每页一个标题 + 2–3 句话，第一页是封面主标题（≤ 12 字）
母稿：<粘贴>
```

### 4.3 口播脚本

```
把下面的母稿改写成 60–90 秒口播脚本。
- 前 3 秒一句钩子，要么反常识、要么直接点人群，≤ 15 字
- 每句话 ≤ 15 字，口语，禁止书面语
- 分镜表形式输出：时间轴 | 口播文字 | 画面内容 | 字幕要点
- 中间至少一次「等一下」式的节奏打断，防止划走
- 结尾 CTA 只给一个动作
- 全片信息点不超过 3 个，多了记不住
母稿：<粘贴>
```

### 4.4 朋友圈

```
把下面的母稿浓缩成朋友圈文案，给 3 个版本：
- A 版：一句话观点 + 一个细节（≤ 60 字）
- B 版：提问式，引发评论（≤ 50 字）
- C 版：场景白描，不讲道理（≤ 80 字）
三版都不要出现链接、不要「详情见公众号」，配图说明单独给。
母稿：<粘贴>
```

## 5. 封面与标题

```
为这条内容写封面文案：
- 主标题 ≤ 12 字，手机上一眼能读完
- 副标题 ≤ 18 字，可选
- 给 8 组候选，并标注每组用的是哪种钩子（身份 / 反常识 / 数字 / 痛点 / 悬念）
- 不要问号堆叠、不要「震惊」「必看」这类平台限流词
内容要点：<粘贴 3 句话>
```

## 6. 发文前质检清单

每条内容发布前逐项勾选。进阶班把它写成 `lint` 脚本。

- [ ] 禁用词扫描通过（医疗/金融/绝对化用语 → `_规范/禁用词.md`）
- [ ] 错别字、数字、人名、机构名核对过
- [ ] 所有 `TODO:` 标记已清掉
- [ ] 数据有出处，出处链接还能打开
- [ ] **AI 生成的画面/配音已打开平台「AI 生成」声明，文案里也说明了**（2025-09-01 起施行的标识办法要求）
- [ ] 字数符合平台（小红书 ≤ 1000、公众号标题 ≤ 20、公众号 API 推送时标题 ≤ 32 字）
- [ ] 话题 / 标签数量符合平台上限
- [ ] 封面在手机上实际看过一遍，字没被裁
- [ ] 开头与其他平台版本不同（防判重）
- [ ] 首评已准备好（发完立刻自己评）
- [ ] 发布时间符合节奏表

## 7. 数据回流表（`publish-log.csv`）

```csv
日期,平台,选题,标题,形态,链接,曝光,阅读/播放,互动,涨粉,备注
```

- 发布后 **48 小时**填一次，**7 天**再填一次（两个时点才能看出是爆发型还是长尾型）
- 「备注」只写假设，例如「换了身份钩子标题」「封面改成大字版」
- 一周一填不要补填，补填的数据没人会分析

## 8. 周报（每周定时任务）

```markdown
# 任务卡：周报

## 输入
- ~/matrix/05-已发布/publish-log.csv 近 7 天
- ~/matrix/_规范/选题标准.md 当前版本

## 输出
写入 ~/matrix/05-已发布/weekly-<YYYYMMDD>.md，包含：
1. 本周发布量（按平台）
2. 表现最好的 3 条与最差的 3 条，各列数据
3. 超过本平台均值 2 倍的条目，逐条给出「可能的原因假设」（标明是假设）
4. **对 选题标准.md 的具体修改建议**：改哪一条、改成什么、依据是哪几条数据
5. 下周待验证的一个假设（只要一个）

## 禁止
- 不要把相关性说成因果
- 样本少于 3 条时直接写「样本不足，不下结论」
```

> 第 4 项是整条流水线唯一的学习机制。**周报不改选题标准，就等于没复盘。**

## 9. 目录规范（发给学员直接照建）

```
~/matrix/
  00-选题池/     topic-YYYYMMDD-关键词.md
  01-素材/       <topic>/（截图、链接、录音、数据）
  02-母稿/       master-<topic>.md
  03-平台稿/
      公众号/    oa-<topic>.md
      小红书/    xhs-<topic>.md
      口播/      script-<topic>.md
      朋友圈/    moments-<topic>.md
  04-成品/       <topic>/（图卡 PNG、封面、成片）
  05-已发布/     publish-log.csv、weekly-*.md
  _规范/         选题标准.md、语气词典.md、禁用词.md、检查清单.md
```

三条铁律：

1. **`<topic>` 一旦定下，六道工序全程用同一个 slug**，Agent 靠它串联上下文
2. **母稿是唯一真相**，平台稿里发现错误要回头改母稿，不能只改一处
3. **`_规范/` 里的文件只在周报后更新**，平时不随手改，否则标准就失去意义
