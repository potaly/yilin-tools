# 匿名访客与埋点 — 需求文档

- 版本：v1.0（2026-10-28）
- 范围：匿名访客 id + 4 个事件 + 后台漏斗与留存
- 上游：`docs/requirements.md`、`docs/aiwei-detector-需求.md`

---

## 1. 要回答的问题

现在答不了的只有两个，这一轮就为它们做：

1. **打开工具的人里，有多少真的用上了？**（漏斗）
2. **上周来的人，这周回来了几个？**（留存）

仓库里原有的统计记的是 **AI 调用的成本**（`calls / tokens / costFen`），
按天、按用户、按 IP 三个维度。它答不了上面两个问题，因为：

- 不调 AI 的工具（AI味检测）完全不在它的视野里
- **IP 算不准回访**。国内移动网络的 IP 会漂（运营商 NAT、4G 切换），
  同一个人下次来大概率是另一个 IP

## 2. 为什么不是登录

**登录是漏斗上的摩擦。** 产品还没被验证"好用"之前加强制登录，
会把试用的人挡在门外，而试用量是现在唯一需要的东西。

正确的中间态是**匿名 id + 埋点**：零摩擦、半天的事。

匿名 id 会被清缓存和换设备冲掉，所以它算出来的留存**偏低**。
这是已知的、可接受的 —— **偏低的真数据，比准不了的 IP 有用得多。**
后台上写了这句话，免得以后自己看到数字先吓一跳。

## 3. 隐私口径

这一轮改了 AI味检测页上的一句文案，因为原来那句变得不准确了：

```
旧：不上传、断网也能用
新：你的文字不会离开浏览器，断网也能用
```

事件体里**只有三个字段**：`{ vid, event, tool }`。
没有文字、没有标题、没有字数、没有 referer。接口层面 `parseTrack()`
是白名单解析而不是过滤 —— 多传的字段根本进不到存储层，有单测守着。

检测本身仍然不依赖网络：埋点发送失败、被拦截、离线，全部静默忽略。

## 4. 实现

```
lib/analytics/events.ts    事件与工具白名单、parseTrack 校验（前后端共用）
lib/analytics/visitor.ts   浏览器端：localStorage 存 uuid、track() 发 sendBeacon
lib/analytics/store.ts     Redis 数据层 + 聚合纯函数（server-only）
app/api/track/route.ts     POST，一律返回 204
```

**事件（只有 4 个）**

| 事件 | 含义 | AI味检测 | 长文图卡 |
|---|---|---|---|
| `open` | 打开工具 | 页面挂载 | 页面挂载 |
| `run` | 点生成 | 第一次粘进非空文本 | 点「AI 排版」 |
| `done` | 生成成功 | 文本 ≥50 字（算一次真检测） | 排版返回成功 |
| `take` | 复制或下载结果 | 点「复制报告」 | 保存单页 / 打包 / PDF |

刻意不做成可扩展的字符串表。事件表一旦放开就会长成一堆没人看的噪音；
要加第 5 个，先回答"它能答哪个我现在答不了的问题"。

**存储（两个键）**

```
events:day:<天>     hash，字段 `<工具>|<事件>` → 计数   TTL 400 天
visitors:day:<天>   set，成员是匿名 id                 TTL 120 天
```

集合大小 = 日活，相邻两个 7 天的交集 = 次周留存。和 `stats:*` 分开放 ——
那套记成本，这套记行为，混在一起两边都会变难读。

**防刷**：按 IP 60 次/分钟（`lib/ratelimit.ts` 新增的 `allow()`）。
正常用一次工具最多发 4 条，这个阈值足够宽松又拦得住脚本。

## 5. 本期不做

- **把额度挂到匿名 id 上**（"不登录 3 次/天"）。仓库里已经有 credits、
  登录、限流三套东西，改配额模型是另一个工程，混进来会很乱
- 「留个邮箱，额度 ×3」的轻钩子 —— 触发它的信号是
  ①AI 账单开始让你犹豫要不要限流，或 ②要第一次回答留存问题。现在都还没到
- 关闭开关 / DNT

## 6. 验证（2026-10-28 实测）

接口对 7 种输入都返回 204（故意不透露校验结果），所以验证是查落库数据：

| 输入 | 落库 |
|---|---|
| 合法 open / done / take | ✅ 各记 1 |
| 坏 vid / 坏 event / 坏 tool / 空 body | ✅ 一条都没进 |
| 合法但夹带 `text: "机密"` | ✅ 记了事件，正文没进存储 |

浏览器端：用全新 profile 的 headless Chrome 打开 `/tools/ai-flavor`，
后台的「今日访客」1 → 2、「打开工具」1 → 2，确认 `track()` 真的发出去了。

`pnpm lint` 干净，`pnpm test` 226 passed，`pnpm build` 通过。
